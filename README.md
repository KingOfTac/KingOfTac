## _Silhouette Generator_

A tool that takes an image and generates a silhouette of the image subject. Uses an image segmentation model to create a mask of the subject for the silhouette.
I threw this tool together in an evening for my wife to use for one of her projects. The tool is deployed to my local network as a docker container with a simple web interface for image upload and customization of output formats.
The tool supports most image formats including HEIF | HEIC.
- `Rust`
- `ONNX`
- `Image Segmentation`
- `Docker`
